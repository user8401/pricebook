# Pricebook

Installable web app (PWA) for Android. Saves a photo, a price and the location (read from the photo's GPS data, or from the phone if the photo has none). Data stays on the phone.

## Publish free on GitHub Pages
1. Create a new public repo, e.g. `pricebook`.
2. Upload all files in this folder to the repo root.
3. Settings > Pages > Source: "Deploy from a branch" > Branch: `main`, folder `/ (root)` > Save.
4. Open `https://<your-username>.github.io/pricebook/` in Chrome on Android.
5. Chrome menu > "Add to Home screen" / "Install app".
